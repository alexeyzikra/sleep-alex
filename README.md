# 🌙 Контроль сна

Трекер сна для студентов: утренний чек-ин за 15 секунд, долг сна, стрики, XP
и уровни. Работает без бэкенда — всё хранится в браузере.

## Запуск

```bash
npm install
npm run dev
```

Сборка в `dist/`: `npm run build`.

## Деплой на GitHub Pages

1. Залить репозиторий на GitHub (ветка `main`).
2. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
3. Пуш в `main` — и `.github/workflows/deploy.yml` соберёт и выложит сайт.

Сайт откроется по адресу `https://<ник>.github.io/<имя-репы>/`. Сборка настроена
на относительные пути (`base: './'` в `vite.config.js`), поэтому подпапка в URL
ничего не ломает.

## На телефоне

Открыть сайт → «Поделиться» → **«На экран „Домой“»**. Это не про иконку:
у обычных сайтов iOS подчищает сохранённые данные, если не заходить неделю,
а у установленного приложения — нет.

## Чего приложение намеренно не делает

- **Не будит.** Браузер не может разбудить при закрытой вкладке — такого API
  нет ни на iOS, ни на Android. Будильник ставится системный, один раз,
  повторяющийся.
- **Не шлёт напоминания.** Локальных уведомлений по расписанию в вебе нет,
  а веб-пуши требуют сервера. Напоминание «пора спать» — тоже системное.
- **Не определяет сон сам.** Данные вводятся руками утром. Это осознанный
  выбор: вечером телефон лучше не трогать вообще.

## Как устроены данные

Всё в `localStorage` под ключом `sleepmaster.v1`. Синхронизации между
устройствами нет — вместо неё экспорт/импорт JSON. Импорт **сливает** записи
по дате (при конфликте побеждает более свежая), так что историю с телефона
и с ноутбука можно свести в одну.

## Логика подсчёта

Запись привязана к **дате пробуждения**: лёг в 01:30 и встал 19-го — это
запись за 19 октября.

XP не хранится отдельно, а каждый раз пересчитывается из записей
(`computeState` в `src/model.js`). Поэтому очки не могут разойтись с историей,
но при смене целевых окон прошлые ночи пересчитываются по новым правилам.

| Действие | XP |
| --- | --- |
| Сон в пределах допуска от нормы | +50 |
| Лёг и встал в целевое окно | +50 |
| Отметил «без телефона перед сном» | +30 |
| Каждая третья ночь подряд по графику | +100 |

Минусов за срыв нет: уровень не откатывается назад, стрик просто обнуляется.
Пропущенный день стрик не рвёт и не продлевает — наказывать за забытую кнопку
нет смысла.

## Файлы

```
src/model.js      арифметика времени, XP, стрики, достижения — чистые функции
src/state.js      localStorage, экспорт/импорт
src/ui/           экраны: дашборд, чек-ин, история, настройки
scripts/          генератор иконок (рисует PNG без внешних зависимостей)
public/sw.js      service worker, офлайн-режим
```
